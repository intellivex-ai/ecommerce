## 2024-04-26 - Unnecessary useSearchParams Hook Usage
**Learning:** In React Router v6, calling the `useSearchParams()` hook subscribes the component to URL search parameter changes. If a component (like `Shop.jsx`) calls this hook but doesn't actually use the returned parameters for rendering logic, it will trigger unnecessary re-renders every time the URL changes. This is an easy-to-miss performance leak, especially if the hook was left behind after refactoring or added solely to satisfy a linter warning about unused variables.
**Action:** When cleaning up unused variables, do not just remove the destructuring assignment (e.g., changing `const [searchParams] = useSearchParams()` to `useSearchParams()`). Entirely remove the hook call and its import if the component no longer depends on URL parameters, as the hook itself introduces a reactive subscription that causes re-renders.
