## 2024-05-24 - Unmemoized Derived State Triggers GSAP Re-animations
**Learning:** In this codebase, GSAP stagger animations are often bound to data changes in child components (like `ProductGrid`). If parent components (like `Shop.jsx`) perform array filtering/sorting outside of a `useMemo` hook, *any* unrelated state update in the parent (e.g., toggling a mobile menu boolean) causes the derived array to be re-created with a new reference. This new reference is passed down, tricking the `useEffect` dependency arrays in child components into thinking the data has changed, which causes the GSAP animations to re-fire unexpectedly and degrade performance.
**Action:** Always wrap expensive, derived lists (like product filtering and sorting) inside `useMemo` hooks, especially when the resulting arrays are passed to components that handle complex animations or data-fetching upon receiving new data references.
