## 2024-03-31 - Memoizing derived arrays to prevent redundant component animations
**Learning:** In React, expensive array calculations (like filtering and sorting products) that occur directly in the render body result in new array references on every render. Even when the input data doesn't change, updates to unrelated state variables (such as a mobile menu toggle) trigger a re-render. These new array references can cause child components that rely on them (especially those managing stagger animations via GSAP) to unnecessarily re-calculate or re-trigger animations, leading to performance jank and redundant DOM operations.
**Action:** Always wrap expensive or derived lists (especially those mapped to animated child components) in a `useMemo` hook to ensure referential stability and skip unnecessary recalculations on unrelated state updates.
