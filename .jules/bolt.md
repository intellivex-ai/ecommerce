## 2024-03-12 - [Memoizing Expensive Calculations in React]
**Learning:** Found a performance bottleneck in `src/pages/Shop.jsx` where a list of products was being filtered and sorted on every render, even when the underlying data or filter criteria hadn't changed. Also discovered that `useSearchParams` from `react-router-dom` was imported and called but never used, which could cause unnecessary re-renders whenever URL parameters changed.
**Action:** Always check for expensive array operations (like chained `.filter().sort()`) inside React components and wrap them in `useMemo` with appropriate dependency arrays. Also, diligently remove unused hooks, especially those like `useSearchParams` or context consumers that subscribe to external state changes and can trigger unwanted re-renders.
