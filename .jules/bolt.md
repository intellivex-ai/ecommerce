## 2024-06-25 - React Component Performance: GSAP Stagger Redundancy
**Learning:** Found a codebase-specific performance pattern in `src/pages/Shop.jsx` where unmemoized array calculations for derived lists (`filtered` products) caused unnecessary recalculations. More importantly, this triggered redundant child component animations (specifically GSAP stagger effects in `ProductGrid.jsx`) on completely unrelated state updates (like toggling `showMobileFilters`).
**Action:** Always wrap expensive derived lists passed to animated components in `useMemo` hooks to prevent unnecessary cascading re-renders and redundant GSAP animation triggers. When a component no longer relies on URL params, fully remove the `useSearchParams()` call and import, rather than just the destructuring assignment, as keeping the call active still subscribes the component to URL changes.
