## 2024-06-06 - Unmemoized arrays breaking GSAP grid animations
**Learning:** In this project's architecture, GSAP animations (like `staggerItems` in `ProductGrid.jsx`) are triggered on the `[products]` dependency array in `useEffect`. If the parent component (`Shop.jsx`) computes the `filtered` products array synchronously on every render without `useMemo`, any unrelated state change (like toggling mobile filters or changing text inputs) creates a new array reference. This not only wastes CPU on O(N log N) sorting, but more critically, it re-triggers the GSAP layout animations on the child component, causing visual jank and layout thrashing.
**Action:** Always memoize derived collections (arrays/objects) that are passed as props to animation-heavy components, ensuring the reference only changes when the actual data or filtering criteria changes.
