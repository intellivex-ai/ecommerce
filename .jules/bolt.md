## 2024-11-05 - Memoizing derived arrays for GSAP animations
**Learning:** Passing unmemoized derived arrays to components with `useEffect` dependency arrays that trigger GSAP layout animations (e.g., `ProductGrid`) causes unnecessary O(N log N) recalculations and layout re-animations on unrelated state changes.
**Action:** Always memoize derived collections passed to animation-heavy components using `useMemo` to preserve reference equality.
