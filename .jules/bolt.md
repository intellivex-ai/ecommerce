## 2024-04-22 - Unmemoized Derived Lists Triggering Redundant Animations
**Learning:** In React components that render lists with GSAP stagger animations (e.g. `ProductGrid`), failing to memoize derived lists (like filtering and sorting operations) causes the child component reference to receive a new array instance on every re-render. If unrelated state (such as `selectedColors` or `showMobileFilters`) is toggled, it forces a re-calculation of the unmemoized array, creating a new reference and incorrectly re-triggering the expensive child GSAP animations.
**Action:** Always wrap expensive derived array calculations (e.g., `.filter().sort()`) in `useMemo` hooks, especially when the resultant array is passed to child components that depend on reference equality to manage heavy side effects like animations or unmounting/remounting DOM nodes.
