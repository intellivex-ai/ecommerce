## 2024-05-01 - Shop Performance Optimization
**Learning:** In the Shop component, unmemoized array calculations for the `filtered` product list cause the array reference to change on every render (even unrelated ones like toggling mobile filters). Since `filtered` is passed as a prop to `ProductGrid`, this triggers `ProductGrid` to unnecessarily re-run its `useEffect` containing expensive GSAP stagger animations on all child components. Additionally, an unused `useSearchParams()` hook subscribes the component to URL changes, causing more needless re-renders.
**Action:** Always wrap expensive derived lists (especially those passed to animation-heavy child components) in `useMemo`. Entirely remove unused hooks like `useSearchParams()` rather than just leaving the call active.
