## 2024-07-04 - Missing Component-Level Route Guards
**Vulnerability:** The `/admin` route lacked component-level authentication guards (`AdminPanel.jsx`), relying only on router-level conditional layout rendering.
**Learning:** Client-side administrative routes must have component-level guards implemented using `useAuth` and `<Navigate>`. Relying on layout wrappers or router conditional logic is insufficient and leaves the actual component exposed to direct URL manipulation. Additionally, hardcoding specific emails (e.g., `admin@velocity.io`) for role-based access control is a recognized code smell and security risk that should be refactored to use formal user roles or environment variables in the future.
**Prevention:** Always enforce access control at the component level using route guards, and ensure early return statements for these guards are placed strictly after all React hook and block-scoped function declarations to avoid Temporal Dead Zone (TDZ) and Rules of Hooks violations.
