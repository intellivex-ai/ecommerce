## 2024-03-05 - Add ARIA labels to Navbar icon buttons
**Learning:** Foundational navigation components often rely on icon-only buttons (Search, User, Cart) which lack accessible names for screen readers. Using `lucide-react` icons directly without `aria-label`s on their wrapper buttons prevents visually impaired users from understanding these global actions. Additionally, dynamic badges like cart counts can be read redundantly if not hidden using `aria-hidden="true"`.
**Action:** When implementing icon-only interactive elements, especially in layout files used across the app, always add descriptive `aria-label` attributes to the button. For buttons containing dynamic indicator badges, apply `aria-hidden="true"` to the badge element and incorporate the dynamic state into the parent button's `aria-label` (e.g. `aria-label="Shopping Cart with X items"`).
