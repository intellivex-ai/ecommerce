## 2024-10-24 - Keyboard Accessibility for Hover-Revealed UI
**Learning:** In this codebase, hover-revealed interactive elements (like Wishlist or Quick Add buttons on Product Cards) use `group-hover:opacity-100`. This hides them from keyboard users who use Tab to navigate, as focus doesn't trigger the hover state.
**Action:** Always pair `group-hover:opacity-100` with `focus-within:opacity-100` (on the container) or `focus-visible:opacity-100` (on the element itself) to ensure interactive elements become visible when they receive keyboard focus.
