## 2024-04-21 - Added Accessibility Attributes to Navbar Icons
**Learning:** Found multiple icon-only interactive elements in the main navigation components (Menu, Search, User, Cart) that lacked accessibility properties, resulting in a poor screen-reader experience. The UI badges conveying dynamic state (e.g., shopping cart items count) were rendered individually from the contextual ARIA label, which would lead to duplicate and confusing screen reader outputs (e.g., "Shopping cart with 3 items 3").
**Action:** Always wrap visual elements within actionable buttons (like icons and contextual badges) with `aria-hidden="true"`, and apply a consolidated descriptive `aria-label` to the parent container itself (e.g., `<button aria-label="Shopping cart with 3 items">...<Icon aria-hidden="true"/><badge aria-hidden="true">3</badge></button>`).
