## 2024-03-17 - Add ARIA Labels to Icon-Only Buttons
**Learning:** Icon-only interactive elements in global layout components like `Navbar` are easily missed by screen readers if they lack `aria-label` attributes. Prioritize adding descriptive `aria-label` attributes to these foundational accessibility components to ensure accessibility across the entire app.
**Action:** Always verify that interactive icon elements (like buttons or links) have proper `aria-label` attributes or visible text to maintain full keyboard and screen reader accessibility, particularly in common layout sections.
